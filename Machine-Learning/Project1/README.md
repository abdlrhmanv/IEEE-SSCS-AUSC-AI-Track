## Project (in the team repo)

Streamlit app for Uber fare prediction: preprocessing, several regressors (including gradient boosting), and a map-based UI.

Clone and run it from that repository, not from this folder.

```bash
git clone git@github.com:AliMohamed3122005/UberPricePredictionProject.git
cd UberPricePredictionProject
pip install -r requirements.txt
# follow that repo's README for the Streamlit entrypoint
```
